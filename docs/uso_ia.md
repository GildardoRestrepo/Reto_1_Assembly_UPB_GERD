## 2. Cómo se usó (división del trabajo)

Una vez claras las decisiones de diseño, división del proyecto por etapas y una estructura de carpetas previa al repositorio. Se usó IA para:
 - Explicar comandos elementales de Github y dar consejos de control de versiones a lo largo del desarrollo del proyecto.
 - Explicar cómo se enlazan diferentes .s en un proyecto SEGGER y ayudar a estudiar la estructura de carpetas necestaria para un proyecto SEGGER cargado a través de ST Link con STM32CubeProgrammer.
 - Construir andamiaje de código .s para etapas iniciales de proyecto (1 y 3).
 - Revisar consistencia en documentación final (y construir estructura de tablas para varios .md del proyecto).
